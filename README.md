# 🤖 ربات تلگرام فارسی ۲۴ ساعته

ربات مدیریت گروه با امکانات کامل به زبان فارسی

## 🚀 امکانات
- مدیریت کامل گروه (ارتقا، عزل، حذف، سکوت)
- بازی حدس کلمه فارسی
- پخش موزیک
- شخصیت شوخ و بامزه
- کیبورد اینلاین

## ⚡ نصب سریع
1. کد را در Railway آپلود کنید
2. توکن ربات را تنظیم کنید
3. ربات به طور خودکار اجرا می‌شود
